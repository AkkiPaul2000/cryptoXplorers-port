# CryptoXplorers

A modern cryptocurrency analytics dashboard built with React and Material UI. Track live prices, market caps, trending coins, and historical price charts for the top 100 cryptocurrencies.

## Features

- Live market data from CoinGecko API
- Global market overview (market cap, volume, BTC dominance)
- Searchable top-100 coins table with pagination
- Trending coins carousel
- Per-coin detail pages with interactive price charts
- Multi-currency support (USD, INR, EUR)
- Responsive dark theme UI

## Getting Started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- React 18
- Material UI 6
- Chart.js + react-chartjs-2
- React Router 6
- Axios

## API

Data is sourced from the free [CoinGecko API](https://www.coingecko.com/en/api).
